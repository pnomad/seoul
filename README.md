# 서울 4박 5일 커플 여행 지도 (2026년 12월, 평일)

대구 출발 → 서울 4박 → 대전 성심당 → 대구. 팝업 · 빵 · 인형뽑기 · 전시 취향에 맞춘 일자별 동선을 지도로 보여주는 단일 HTML 앱입니다.

## 쓰는 법
- `index.html`을 브라우저로 열면 끝 (서버·빌드 없음). GitHub Pages로 켜면 폰에서도 바로 열 수 있어요.
- **여행 주간 토글**: 12/7–11 vs 12/14–18 — 해당 주간에 아직 안 열 가능성이 있는 일정은 흐리게 표시.
- **D1~D5 / 전체** 탭: 일자별 번호 핀 + 이동 경로.
- **카테고리 필터**: 팝업 · 빵 · 뽑기·가챠 · 전시 · 크리스마스 · 교통.
- 맛집 카테고리 + Day별 '오늘의 맛집' 요약, 대안 식당
- 카드 클릭 → 지도 이동, 각 장소에 네이버지도 / 카카오맵 바로가기.
- 체크리스트(예매 등)는 브라우저에 저장됩니다.

## 숙소
- **1·2박 H Avenue 건대성수점**(92,642원, 체크인 18시) + **3·4박 더 스퀘어 호스텔 종로**(89,733원, 체크인 15시). 매일 점심 후 휴식: Day 1·2는 카페, Day 3·4는 숙소.

### 숙소 후보 메모
- **종로3가·익선동 4박 고정** 추천: 명동보다 저렴하고 1·3·5호선 + 2호선(을지로3가)까지 닿음, 3일차 밤 도보 귀가.
- 가격대(검색 기준): 익선동 호텔 최저 4만원대, 종로3가 모텔 6~8만원대 → 4박 약 24~32만원.
- 직접 찾은 후보: 더 스퀘어 호스텔 종로(89,733원), 아늑 안국 2호점(107,326원, 조식), 탑 호텔 앤 레지던스(122,490원), 케이브 료칸 종로(수표로22길 10)
- 그 밖의 후보: 종로 부티크 호텔K, 리안 호텔, 나포레, 그리드인호텔, 엠지호텔. 날짜 넣고 네이버호텔·여기어때·야놀자·아고다 비교 후 무료취소로 예약.

## 지도 표시 방식
- 지도 이미지(OpenStreetMap/CARTO 타일)를 불러올 수 있으면 일반 지도 위에 표시합니다.
- 타일이 막힌 환경(claude.ai 링크 페이지, 오프라인 등)에서는 자동으로 `seoul-geo.js`의 **실제 서울·대전 구 경계 + 한강**을 그려 바탕 지도로 씁니다.
  구 경계 출처: npm 패키지 [korea-sigungu-geocoding](https://github.com/sh5080/korea-sigungu-geocoding) (MIT). 한강은 강 남북 구의 경계선에서 계산했습니다.

## 실제 지도로 보기
- 장소 사이 이동 안내 줄의 **카카오맵 · 구글** 버튼 → 그 구간의 대중교통 길찾기가 열립니다. (구글 지도는 한국에서 자동차 길찾기와 대중교통 경유지를 지원하지 않아 하루 전체 경로 버튼은 뺐습니다.)
- 장소별 네이버지도/카카오맵 버튼으로 정확한 위치·영업시간 확인.
